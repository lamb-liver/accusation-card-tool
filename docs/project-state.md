## Main Purpose

`accusation-card-tool` is a Vite + React PWA for the card game `控訴`. It provides card lookup, filtering, deck building, community sharing, QA, and match-side utilities for players.

## Existing Features

- Card gallery and search: normalized keyword search with name-first ranking, plus faction, type, symbol, and mechanic filters. Golden queries live in `scripts/test-search.mjs`.
- Card detail modal: large image, metadata, complete effect text, and alternate-art support.
- Deck builder: leader / ritual / main deck sections, deck rules, drag sorting, saved decks, import/export, text export, JSON export, and image export.
- QA: built-in FAQ content generated by `scripts/sync-qa.mjs` into `src/data/qaData.js`.
- Community/share wall: public deck sharing, deck detail routes, guestbook, and admin moderation. Local drafts may be incomplete; public submissions must contain exactly 1 leader, 3 rituals, and 20 main-deck cards on both frontend and backend.
- PWA/static assets: one `public/cards.json` catalog, responsive card images, Workbox service worker, and installable browser app.
- Match clock: two-player clock with pause/resume/reset, turn switching, low-time states, and coin-flip setup.

## Content Trust Boundary

- `public/cards.json` and generated `src/data/qaData.js` are scanned by `scripts/check-content.mjs` before build and during `validate:repo`.

## Validation Commands

Run these before reporting completion:

```bash
npm run validate:repo
npm run build
npm run validate:browser
```

`validate:browser` covers the six main modes at 320, 390, 768, and 1280 pixels, including page overflow, visible control bounds, rendered images, internal links, the mobile filter drawer, and the card modal.

If one fails, fix only the relevant cause. Do not use validation failures as a reason to refactor unrelated app areas.
